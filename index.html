x64 architecture Canary release Open source

The first major milestone.

Brack OS began as an experiment in understanding how operating systems work from the ground up. Today, that work has reached its first x64 Canary release.

The Canary is an early build and the project is still evolving, but Brack OS can now boot on real x64 hardware as well as in QEMU.

Built from the ground up.

Brack OS is an open-source operating system project focused on learning, experimentation, and exploring computing from the lowest levels upward.

◉

Our own kernel

Brack OS is built around its own kernel rather than relying on an existing operating system kernel.

Open source
