About Brack OS

Brack OS is an open-source os for (hopefully someday) all platforms. Right now, it only operates on 16 bit CPUs, but hopefully soon that will change.

Devs: Brent R. Jack C. Noah H. Jayden L.

Upcoming platforms (in order of priority) AMD64, ARM32, i386/x86, ARM64. Once we get all/most architectures working, we will start developing a GUI. Expect that to be after a few years. Until then, thanks for reading.
