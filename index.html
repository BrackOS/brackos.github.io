The Project

Why build an operating system?

An operating system is the software layer that manages a computer's hardware and provides the foundations for other software to run.

BrackOS is built from the ground up as an open-source project. Instead of relying on an existing operating system kernel, we work directly with processors, memory, bootloaders, hardware, and the other pieces that make a computer work.

The project is educational, experimental, and continuously evolving.
