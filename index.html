Open-source operating system

Built from the ground up.

Brack OS is an experimental open-source operating system built from the ground up, with a focus on learning, experimentation, and exploring how operating systems work.

Explore Brack OS View the roadmap View on GitHub

Why Brack OS?

Brack OS is a project built to explore the foundations of computing, one part of the system at a time.

◉

Custom Kernel

The foundation of Brack OS is its own kernel, developed as part of the project rather than relying on an existing operating system kernel.

◇

Open Source

The project is open source, allowing anyone to explore the code, follow development, and contribute.

⬡

Multiple Platforms

x64 is the current focus, with ARM64, x86, ARM32, and potentially other architectures planned for the future.

Current status

Brack OS is still in development. It is not currently ready for a canary release, but development is ongoing.

Where we're going

Brack OS has a long way to go. We're starting with the kernel and working toward drivers, userspace, and eventually a graphical interface.

Kernel

Build and improve the foundations of the system.

Drivers

Expand hardware support across platforms.

Userspace

Develop the software that runs on top of the kernel.

GUI

A graphical environment is a long-term goal.
