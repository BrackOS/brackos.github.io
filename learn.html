How does an OS actually work?

Brack OS is being built from the ground up. Here's a simple look at what we're building and why.

So... what is an operating system?

An operating system is the software that sits between your computer's hardware and the programs you use every day.

Windows, macOS, and Linux are all operating systems. They handle things like memory, processors, storage, devices, and running applications.

Brack OS is our attempt to build one ourselves.

What's a kernel?

The kernel is one of the most important parts of an operating system. It is responsible for communicating with the hardware and providing the foundations that the rest of the system can use.

CPU

The kernel manages how the system uses the processor and handles the code that needs to run.

Memory

The kernel keeps track of memory and determines how it is used by different parts of the system.

Hardware

Drivers allow the operating system to communicate with hardware such as storage devices, keyboards, displays, and network hardware.

Processes

The kernel provides the foundation for running programs and managing the resources they need.

Why build a kernel from scratch?

There are already plenty of excellent operating systems. So why make another one?

Because building one is a great way to understand how computers actually work.

Instead of starting with an existing operating system and changing it, Brack OS lets the team work on the foundations themselves. Every part of the system is an opportunity to learn, experiment, and solve problems.

What are architectures?

You may have noticed that Brack OS has pages for x64, x86, ARM64, ARM32, and even 16-bit systems.

These are different processor architectures. They define, among other things, the instructions a processor understands and how software interacts with it.

x64

The current primary development target for Brack OS.

x86

The older 32-bit version of the x86 processor family.

ARM64

A modern 64-bit ARM architecture used by many newer devices.

ARM32

The older 32-bit ARM architecture.

16-bit

An experimental target intended primarily for exploration and learning.

RISC-V

A possible future architecture target for Brack OS.

Why isn't everything working yet?

Because operating systems are complicated.

Getting a kernel to start is only the beginning. Drivers, storage, networking, memory management, userspace programs, and eventually graphical interfaces all have to be built and tested.

Right now, Brack OS is still focused on its foundations. Some features and commands are not functional yet, and that's expected at this stage of development.

Where do we go from here?

The long-term goal is to turn the foundations of Brack OS into a complete operating system that can run useful software across multiple architectures.

We're starting with the kernel, then moving toward drivers, userspace, and eventually a graphical environment.
