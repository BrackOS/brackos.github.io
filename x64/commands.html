Command 01 System Information

help

Displays all available commands with brief descriptions.

Usage

BrackOS> help
Available commands:
  help          - show this help message
  echo <text>   - print text to screen
  clear         - clear the screen
  info          - show system information
  mem           - show memory layout
  cpu           - show CPU information
  ...and more

Use case

Get a list of all commands at any time.

Command 03 System Information

cpu

Displays CPU information and the current mode.

Usage

BrackOS> cpu
CPU Information:
  Instruction Set: x86-64 (AMD64)
  Mode: 64-bit Long Mode
  Paging: Enabled (2MB pages, PML4/PDPT/PDT hierarchy)
  PAE: Enabled (Physical Address Extension)
  GDT: Loaded (3 segments: null, code, data)
  IDT: Not implemented
  Interrupts: Disabled
  Exception Handling: None

Use case

Debug and understand CPU state. Useful for kernel developers.

Command 12 Advanced

repeat <n> <cmd>

Executes a command multiple times. Currently only echo is supported.

Usage

BrackOS> repeat 3 echo BrackOS
BrackOS
BrackOS
BrackOS

Use case

Testing and demos. <n> is the repetition count (1-100); <cmd> is the command to repeat.

Command 13 System Control

shutdown

Halts the system by executing the CPU HLT instruction. The system cannot resume without a power cycle, and no state is saved.

Usage

BrackOS> shutdown
Shutting down...
[CPU halts]

Use case

Clean system shutdown without power-off.

Command 14 System Control

reboot

Restarts the system by sending a reset command to the keyboard controller (port 0x64), causing a warm restart.

Usage

BrackOS> reboot
Rebooting...
[System restarts from bootloader]

Use case

Restart for applying changes or recovery.

Error Handling

Unknown commands

If BrackOS does not recognize a command, it displays an error message in red and returns to the shell prompt. 

BrackOS> xyz
error: unknown command: xyz

BrackOS>

Error behavior

  • The error text is displayed in red.
  • The exact text entered is included in the error.
  • The text color returns to gray afterward.
  • The cursor moves to the next line.
  • A new green command prompt appears.

repeat with an unsupported command (anything other than echo) produces no output.

Shell behavior

The shell has a few rules worth knowing when entering commands.

Empty lines

Pressing Enter with nothing typed does nothing and returns to a new prompt.

Spaces only

A line containing only spaces is treated as empty.

Case sensitive

Commands must be entered in lowercase. HELP and Help are not valid commands.

Partial commands

Partial names do not match commands. hel and clea are invalid.

Technical Detail

Command length

The shell uses a 256-character command buffer. Input is limited to 255 characters plus the terminating null character.

Input longer than the available buffer is silently truncated.
