Brack OS commands.

A reference for the commands currently available in the Brack OS command-line interface.

Brack OS is still under development. Some commands are experimental or currently unavailable. Networking commands in particular will not work yet because Ethernet driver development has only recently begun.

One thing to know first

Brack OS currently uses A: as its main drive. If you've used Windows before, you may recognize that letter from floppy disks.

Linux and macOS normally use / for the root of the filesystem, while Windows normally uses C:. Brack OS currently uses A:.

System commands

Commands for controlling and interacting with the operating system.

help Working

Displays information about available commands.

shutdown Working

Shuts down Brack OS.

die Working

Shuts down the system.

reboot Working

Restarts Brack OS.

Administration

Commands that require administrator privileges.

adm Experimental

Runs a command with administrator privileges. adm is pronounced "Adam" and is short for administrator.

User management

addme Experimental

Adds a user to the system. User management is still under development.

delme Experimental

Removes a user from the system. User deletion is currently difficult to perform and remains under development.

Filesystem

nf Working

Creates a directory.

Package management

Package management is planned, but these commands are not functional yet.

update Not functional

Intended to update installed software and packages.

bndl Not functional

Intended for managing or installing software packages.

Networking

Networking support is currently being developed. Ethernet drivers have only recently entered development, so networking commands are not functional yet.

ip Not functional

Intended to display network information once networking support is available.
