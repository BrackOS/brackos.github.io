Roadmap

Where BrackOS is going.

BrackOS is being developed one milestone at a time. Here's where the project is now, what's coming next, and where we want to go in the future.

The Road Ahead

From kernel to operating system.

BrackOS does not follow a rigid development schedule. Instead, development moves through major milestones as the project and its kernel mature.

Current

x86 & x64 Canary / Beta

BrackOS has released its first x86 and x64 operating system kernels. Both versions currently provide a command-line interface and form the foundation for continued development.

Released

Next Release

x64 Non-Beta Release

The x64 version will move beyond its beta stage into a normal, non-beta release.

Target: December 10, 2026

Following

x86 Non-Beta Release

The x86 version will receive its normal, non-beta release shortly after the x64 release.

This release will remain CLI-only.

Future

ARM32 & ARM64

ARM32 and ARM64 versions of BrackOS are planned for future development.

Neither architecture has been released yet, and there is currently no public release date.

Long Term

Graphical User Interface

A graphical user interface is a long-term goal for BrackOS.

GUI development is expected much later in the project's development, after the command-line foundation and underlying operating system have grown substantially.

A Living Roadmap

Plans can change.

BrackOS is an actively developing open-source project. As development continues, milestones may be added, changed, or reordered. Specific dates are only listed when the team has committed to them.
