Roadmap

Where BrackOS is going.

BrackOS is being developed one milestone at a time. There is no rigid development schedule, but there is a clear direction for the project.

The Road Ahead

From kernel to operating system.

Each milestone builds on the one before it. Dates are only listed where the team has made a specific commitment.

Current

x86 & x64 Canary / Beta

BrackOS has reached its first released stage on both x86 and x64. These releases provide the foundation for continued kernel development and testing.

Both architectures are currently CLI-only.

Next Major Milestone

x64 Non-Beta Release

The x64 kernel will move from its beta stage to a non-beta release.

Target: December 10, 2026

Planned
Following

x86 Non-Beta Release

The x86 kernel will receive its non-beta release shortly after the x64 release.

This release will also remain CLI-only.

Planned
Future

ARM32 & ARM64

ARM32 and ARM64 versions of BrackOS are planned for the future.

Development and release timing has not been finalized.

Future
Long Term

Graphical User Interface

A graphical interface is a long-term goal for BrackOS. It will come much later in the project's development, after the underlying operating system has grown substantially.

There is currently no target date for a GUI release.

Long Term
A Living Roadmap

Plans can change.

BrackOS is being developed by a small team, so the roadmap may change as the project evolves. We will avoid assigning artificial deadlines to milestones that do not have a committed date.
