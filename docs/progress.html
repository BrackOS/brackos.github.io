Project Status

BrackOS Progress

A quick overview of what the team is actively building, what is still experimental, and what is planned for the future.

Development Notes

What we're working on now.

Progress is measured on a scale of 1-10, where 1 means just started, 5 means working but buggy and unreleasable, and 10 means it is close to being release-ready.

Priority level carries no guarantees for release dates or anything of the sort. 1 is the lowest and 5 is the highest.

This page is intentionally rough and easy to update as development changes.

Filesystem

Native Filesystem named BRKS

Progress: 6/10

Priority: 2/5

A native filesystem to give us more than FAT32 can provide. Jack is developing a driver for Linux so it will be usable beyond just BrackOS.

The driver will be released later, probably not when the filesystem launches. This code has already been released in the source tree, but it will remain beta until further testing.

Primary dev(s): Jack

User Interface

Basic GUI

Progress: 2/10

Priority: 1/5

The goal is straightforward: get a basic GUI running. Development is slow because time is limited, and much of the work is repetitive and tedious.

The team has drafted a local Chinese AI to help with the boring parts.

Primary dev(s): Jack, Jayden, Deepseek-r1:14b :)

Networking

Very basic Ethernet support

Progress: 3/10

Priority: 4/5

Intel e1000 support for BrackOS. For now this works in QEMU, though it may also work on real hardware if the machine has an e1000 card.

The current implementation is a constant polling loop on the PCI bus, and only the ping command is functional. But it works.

Once DNS is in place, installing apps via the bndl command will be possible by downloading application manifests from a GitHub repo.

Primary dev(s): Jack

Future Work

Planned next steps

USB support

Progress: 0/10

Priority: 0/5

One of the hardest parts of building an operating system is writing drivers, and BrackOS is no exception. USB support may eventually include basic drive access, keyboard support, and mouse support, but it is likely still years away.

Primary dev(s): None. If you would like to help contribute, please reach out through the project channels.
