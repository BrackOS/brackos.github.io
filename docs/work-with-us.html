Get Involved

Help build BrackOS.

BrackOS is an open-source operating system project. Whether you want to write kernel code, test hardware, improve documentation, or help in another way, there's room for contributors.

Contributing

There are plenty of ways to help.

You don't have to be one of the core developers to contribute to BrackOS. The project is still young, which means even relatively small improvements can make a meaningful difference.

Helpful

Testing

Test the kernel, new features, and report back what works, if anything needs improvement, and what you think we should add.

Needed

Blog

Write blog posts about the releases and anything else we would like you to write about. Any help would be wonderful, but ideally it would be one post every two weeks.

Critical, most needed

Documentation

Improve technical documentation, write guides, clarify confusing information, or help keep the website accurate as BrackOS changes. Our current docs are badly out of date, the README hardly matches what features there are, and there are numerous other things that are out of date.

Needed

Help write code

Currently we have one person writing all the code, and he does not have much time. Naturally, this limits development, and so we are asking for help. ANY AMOUNT IS WELCOMED! We welcome any developer who wants to code, but please understand that this kernel currently only has C and assembly as usable languages. If you would like to port your favorite language over so you can code in it, we would welcome you to contact us so we could arrange for you doing that.

Important

BrackOS is usually unpaid.

BrackOS is primarily a volunteer open-source project. There is currently no guaranteed pay for contributors, and contributing should not be treated as a paid job unless the team explicitly agrees otherwise.

We value the work people put into the project, even when that work is voluntary.

Contributors

Get recognized for your work.

Meaningful contributors can have their names listed on the BrackOS website as developers. We want the people who help build BrackOS to receive credit for the work they put into it.

Contributions are reviewed on a case-by-case basis; simply submitting a pull request with a minor change does not necessarily make someone a BrackOS developer.

Getting Started

Want to contribute?

Start by exploring the BrackOS source code and documentation. Find something you'd like to improve, test the project, or talk with the team about an idea.

BrackOS is built in the open, so you can see what we're working on and learn about the project before deciding how you'd like to help.
