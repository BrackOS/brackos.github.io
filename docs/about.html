About BrackOS

Built from the ground up.

BrackOS is an open-source operating system project built by a small team with a focus on low-level development and learning by building.

The Project

What is BrackOS?

BrackOS is an open-source operating system project developed from the ground up. The project explores operating system development at a low level, from boot processes and CPU initialization to hardware interaction and kernel development.

BrackOS is developed independently and is not based on the Linux kernel.

Open Source

Built in the open.

BrackOS is released as open-source software under the MIT License. The project is intended to remain accessible to people who want to explore, learn from, or contribute to its development.

As BrackOS develops, this website will document releases, technical details, development plans, and ways to get involved.
