The Basics

What is an operating system?

An operating system, or OS, is the software that sits between a computer's hardware and the programs that use it.

When you turn on a computer, something has to initialize the processor, manage memory, communicate with hardware, and provide a way for software to actually run. An operating system provides the foundation for all of that.

Windows, macOS, Linux, Android, and many other systems are operating systems. They can look very different, but underneath the user interface they all have to solve many of the same fundamental problems.

Why BrackOS?

Why build an operating system?

Most people use an operating system without ever needing to think about what happens underneath it. BrackOS gives us an opportunity to work directly with those underlying systems.

Building an operating system means dealing with things that are normally hidden behind layers of existing software: CPU modes, memory, bootloaders, hardware devices, assembly code, and the kernel itself.

It's a difficult project, but that difficulty is part of the point. By building the system ourselves, we can learn how computers work at a much deeper level.

How It Works

From power-on to programs

1. Hardware

The processor starts executing instructions according to the platform's boot process.

2. Bootloader

A bootloader loads the operating system kernel and gives it the information it needs to begin running.

3. Kernel

The kernel takes control of the system and provides the fundamental software layer that interacts with the hardware.

4. Drivers & Hardware

The operating system needs ways to communicate with devices such as keyboards, displays, storage, and other hardware.

5. Programs

Software can then use the facilities provided by the operating system to perform useful work.

BrackOS Today

Starting small.

BrackOS is currently a small kernel project. Its released x86 and x64 versions provide a foundation for further development, including booting the kernel, displaying text, receiving keyboard input, and providing a basic command shell.

There is a lot left to build. That's intentional. BrackOS is a project that grows one subsystem at a time.
