Technical Documentation

BrackOS x86

A look under the hood at the boot process, kernel, display, keyboard, memory, and shell.

Architecture

BrackOS x86 is the 32-bit x86 release of BrackOS. It is designed as a small, freestanding kernel with direct hardware access and a simple command shell.

CPU

x86-32

The kernel targets 32-bit x86 processors and is built as a freestanding kernel rather than a conventional userspace application.

Boot

GRUB / Multiboot

GRUB is responsible for loading the kernel and transferring control to its entry point.

Memory layout

The kernel begins at 1 MiB and uses a linker script to organize its code and data into aligned sections. 

0x00000000
     │
     │ Reserved / boot memory
     │
0x00100000  ← Kernel starts
     │
     │ .text
     │ .rodata
     │ .data
     │ .bss
     │
     ▼

0x000B8000  ← VGA text buffer

A fixed stack is allocated in the kernel's uninitialized data section. There is no heap or dynamic memory allocator.

VGA display

The x86 kernel writes directly to the VGA text buffer at 0xB8000. 

Resolution: 80 × 25 characters
Foreground:  16 colors
Background:  8 colors
Buffer:      0xB8000

The display driver handles character output, newlines, scrolling, clearing the screen, colors, cursor positioning, and backspace.

Input

PS/2 keyboard

Keyboard input is obtained by polling the PS/2 controller. 

Data port:    0x60
Status port:  0x64
Input:        Scancode set 1

Shift keys are supported, allowing uppercase letters and shifted symbols. The polling loop uses the x86 pause instruction while waiting for input.

Kernel structure

boot.s

Boot entry point, initial stack setup, and transition into the C kernel.

kernel.c

Main kernel logic, shell, command parsing, line input, and string utilities.

vga.c / vga.h

VGA text output and screen management.

keyboard.c / keyboard.h

PS/2 keyboard polling and scancode handling.

io.h

Low-level I/O port helpers and MSR access utilities.

linker.ld

Defines the kernel memory layout and section placement.

grub.cfg

GRUB boot configuration used to load BrackOS.

Current limitations

What isn't here yet?

  • No filesystem or disk driver
  • No multitasking
  • No networking
  • No dynamic memory allocator
  • No timer subsystem
  • No USB support
  • No graphics subsystem beyond VGA text mode
  • No interrupt-driven device handling
