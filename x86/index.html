BrackOS for x86

A minimal operating system kernel built from scratch for 32-bit x86 systems.

Download ISO View Source
Architecture

x86-32

BrackOS runs as a 32-bit x86 kernel.

Boot

BIOS & UEFI

The release supports booting through both BIOS and UEFI configurations.

License

MIT

BrackOS is open source and released under the MIT License.

What's included?

The x86 release provides a small but functional kernel with basic hardware interaction and a command shell.

VGA display

BrackOS uses VGA text mode for its display, including text colors, scrolling, and backspace handling.

Keyboard input

A PS/2 keyboard driver handles keyboard input and basic shift-key support.

Command shell

The kernel includes a simple interactive shell for running built-in commands.

GRUB boot

BrackOS uses GRUB with Multiboot support to load the kernel.

Current limitations

Still under development

BrackOS is a developing operating system. The current kernel does not yet provide many facilities normally expected from a general-purpose operating system.

  • No filesystem
  • No multitasking
  • No networking
  • No virtual memory
  • PS/2 keyboard input
