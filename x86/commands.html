Command Reference

BrackOS x86 Commands

Everything currently available in the BrackOS command shell.

Command

help

Displays all available commands.

Command

echo <text>

Prints text to the screen.

Command

clear

Clears the screen and returns the cursor to the top.

Command 01

help

Displays all commands currently available in the BrackOS shell.

Usage

BrackOS> help
Available commands:
  echo <text>   - print text to screen
  clear         - clear the screen
  help          - show this help message

Arguments

help does not require any arguments.

Command 02

echo <text>

Prints the supplied text to the screen.

Usage

BrackOS> echo Hello World
Hello World

BrackOS> echo This is BrackOS
This is BrackOS

Without text

Running echo without any text prints a blank line. 

BrackOS> echo

BrackOS>

Special characters

Text can contain spaces, numbers, and special characters. 

BrackOS> echo test123!@#
test123!@#
Command 03

clear

Clears the entire screen and moves the cursor back to the top-left corner.

Usage

BrackOS> clear

Effect

The screen is erased and filled with the default black background. The cursor is reset to the top-left position.

Error Handling

Unknown commands

If BrackOS does not recognize a command, it displays an error message in red and returns to the shell prompt. 

BrackOS> xyz
error: unknown command: xyz

BrackOS>

Error behavior

  • The error text is displayed in red.
  • The exact text entered is included in the error.
  • The text color returns to gray afterward.
  • The cursor moves to the next line.
  • A new green command prompt appears.

Shell behavior

The shell has a few rules worth knowing when entering commands.

Empty lines

Pressing Enter with nothing typed does nothing and returns to a new prompt.

Spaces only

A line containing only spaces is treated as empty.

Case sensitive

Commands must be entered in lowercase. HELP and Help are not valid commands.

Partial commands

Partial names do not match commands. hel and clea are invalid.

Technical Detail

Command length

The shell uses a 256-character command buffer. Input is limited to 255 characters plus the terminating null character.

Input longer than the available buffer is silently truncated.
