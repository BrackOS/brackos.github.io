Near-term goals

These are the milestones we're currently aiming for. Dates may move as development and testing continue.

x64 Canary

Target: September 20, 2026. Get an early experimental x64 build into the hands of testers.

x64 v0.1

Target: October 15, 2026. Work toward the first stable Brack OS x64 release.

More hardware

Expand hardware support, fix bugs, and make the kernel more reliable across different x64 machines.

ARM32

Begin work toward ARM32 support, with a Canary target in early 2027.

Expanding the platform

Once the foundations are stronger, we'll start bringing Brack OS to more architectures.

64

ARM64

A high-priority future target. ARM64 support will expand the range of modern hardware that can potentially run Brack OS.

32

x86

Bring Brack OS to older 32-bit systems after the higher-priority architecture work progresses.

A

ARM32

Develop a lightweight ARM32 kernel and work toward a reliable release for compatible hardware.

The long-term vision

The kernel is only the beginning. Eventually, Brack OS should become a complete operating system.

Kernel

Build a reliable, portable kernel across multiple CPU architectures.

Drivers

Add the hardware support needed for Brack OS to run on real-world computers.

System software

Build the tools and core software needed to turn the kernel into a usable operating system.

GUI

Once the foundations are ready, begin work toward a graphical desktop environment.

One step at a time

We're a small team working on Brack OS in our spare time. The roadmap will change as we learn, build, break things, and figure out what comes next.

That's part of the fun.
