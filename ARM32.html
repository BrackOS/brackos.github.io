Architecture / ARM32

ARM32

A future architecture target for bringing Brack OS to 32-bit ARM hardware.

Future development

ARM32 is planned for development after the current higher-priority architecture work progresses.

The plan

ARM32 is currently planned as an important future target. The team is hoping for a Canary build in early 2027.

A stable 0.1 release is tentatively hoped for in summer 2027. These are development goals, not guaranteed release dates.

What we're aiming for

Canary

A first experimental build is hoped for in early 2027.

Version 0.1

The current goal is a stable 0.1 release around summer 2027.

Architecture

ARM32 will provide support for compatible 32-bit ARM processors.

Flexibility

The architecture is part of the larger effort to make Brack OS useful across different types of hardware.

Follow the project

Once builds become available, source code and downloads will be published through the Brack OS project.
