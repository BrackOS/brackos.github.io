Our first x64 release.

Brack OS x64 is the project's current primary architecture, and this release marks an important step from development toward something people can actually boot and try.

It can boot on real x64 hardware and can also be run through QEMU. This is an early build, so Brack OS will continue to change and improve as development moves forward.

Download Brack OS x64 Boot instructions

So, what is it?

Brack OS x64 is the current foundation of the project: an operating system kernel being built from the ground up.

◉

Built from scratch

Brack OS is an independent operating system project, built to explore how the pieces of an operating system come together.

◇

Runs on real hardware

The x64 build can boot on real x64 machines as well as in a virtualized QEMU environment.

⬡

Still growing

This is an early development build, not the finished operating system. There is plenty more to build as Brack OS develops.

An early look at Brack OS.

This release is an important milestone, but it is still very much a work in progress.

Early software

This is an experimental development build. Things may be incomplete, change over time, or not work exactly as expected. That's part of releasing early and continuing to build from there.
