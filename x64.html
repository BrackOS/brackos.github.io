Architecture / x86-64

The x64 kernel

The primary development target for Brack OS and the foundation we're currently building the system around.

Current focus

x64 is currently the highest-priority architecture for Brack OS development.

Where things stand

Development of the x64 kernel is ongoing. The project is still too early for a public canary release, but the goal is to reach that point soon.

We are currently aiming for a canary build around September 20, 2026, followed by a hoped-for version 0.1 release around October 15, 2026. These dates are goals rather than guarantees.

What comes next?

Kernel development

Continue improving the core of the operating system and resolving bugs as development progresses.

Hardware support

Expand driver and hardware support so the system can become useful on a wider range of machines.

Canary release

Once the kernel reaches a suitable level of stability, a public experimental build can be made available.

Long-term goal

x64 is only the beginning. The larger goal is a complete operating system with support for multiple architectures.

Get the source

When builds become available, the source code will be available through the Brack OS GitHub repository.
