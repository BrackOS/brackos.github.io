Architecture / x86

The x86 kernel

A planned 32-bit architecture target for Brack OS.

Planned platform

x86 is a high-priority future architecture, but development has not reached the point where a release date can be estimated.

Why x86?

Supporting x86 would allow Brack OS to reach older 32-bit computers that are no longer suitable for many modern operating systems.

It also presents an interesting technical challenge: building a modern operating system while working within the constraints of older hardware.

Development priority

Priority

High priority, but behind the current x64 development work.

Release date

No estimate is currently available.

Target

32-bit x86-compatible processors.

Future

Development will become more practical once the core system is further along on x64.

Follow development

There is currently no downloadable x86 build. Development updates and source code will be shared through the project repository.
