Architecture / 16-bit

Where Brack OS began.

The 16-bit kernel was the original starting point for the Brack OS project.

Historical project

The original 16-bit kernel is currently unavailable because the legacy USB drive containing it was lost.

The beginning

Before Brack OS was focused on x64, the project started with a 16-bit kernel. It was the first experiment that eventually grew into the larger operating system project.

Although the original kernel is no longer available, the project itself continued and eventually shifted its primary focus toward x64.

What happens next?

The 16-bit kernel is no longer the primary development target. It may ultimately be the last kernel released in the project, although that remains uncertain.

If a build becomes available in the future, the source code will be published through the Brack OS GitHub repository and a download will be added here.
