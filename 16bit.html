16 bit ClI OS info

The 16 bit kernel was initially what got the BrackOS project started.

However, the legacy usb drive which it was stored on has been lost, so we unfourtunately do not have the kernel.

Because of this, x64 has replaced the 16-bit kernel in order of priority, and it may very well be the last kernel that comes out.

Once either build is out, you can get the code can instantly at our github, or you can come back here where a download button will be posted.
