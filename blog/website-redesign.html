Welcome to the new Brack OS website

A new look for the project as development continues.

A fresh start

The Brack OS website has gotten a major redesign. The old site was functional, but it was very much a work in progress and didn't do a great job of explaining what Brack OS actually is.

The new design is meant to make the project easier to understand, whether you're already familiar with operating system development or you're just someone who thinks building an operating system sounds really cool.

Less terminal, more approachable

Brack OS is currently a command-line-based project, but that doesn't mean the website needs to look like a terminal.

We've moved toward a cleaner card-based design with a darker, blue-toned interface. The goal is to make the site feel like a modern technology project without making it look like you're about to accidentally install something dangerous on your computer.

What's happening with Brack OS?

The project is still in early development. Our current focus is the x64 kernel, with other architectures planned for the future.

There's still a lot of work ahead, including kernel development, drivers, userspace, and eventually a graphical interface.

If you'd like to see where everything is headed, check out the Brack OS roadmap.

What's next?

We're continuing development toward the first Canary builds. As the project develops, we'll use this blog to share updates, development milestones, announcements, and other things happening behind the scenes.

Thanks for checking out Brack OS. We're still early in the journey, but we're excited to see where it goes.
