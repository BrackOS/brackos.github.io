Refactoring the BrackOS Website

September 20, 2026 · We're rebuilding the website from the ground up alongside the next stage of BrackOS.

The BrackOS website has had a bit of a history. As the project grew, so did the number of pages, descriptions, technical details, and bits of documentation scattered across it.

Eventually, some of those pages stopped agreeing with each other. Some information was outdated, some of it described older versions of the project, and the overall structure wasn't particularly easy to maintain.

So we're starting over.

Rather than continuing to patch an increasingly complicated website, we're rebuilding the site around a much simpler structure.

The goal isn't to make the site complicated. It's the opposite: important information should be easy to find, easy to understand, and easy for us to update when BrackOS changes.

The new site

One project, one source of information.

The new site is being organized around the operating system itself: releases, technical documentation, commands, development information, the project roadmap, and updates from the team.

BrackOS has changed too.

The website refactor is happening at an important point for the project. BrackOS now has released x86 and x64 kernels, giving us something substantial to document and build on.

The current systems are intentionally low-level and CLI-focused. They aren't trying to be a desktop operating system yet. The project is still building the foundations that future versions can grow from.

Keeping the site maintainable.

One of the biggest changes is how we're organizing information. Instead of having large pages trying to explain everything at once, we're separating different parts of the project into focused pages.

The blog is also designed to make future updates easier. Posts are indexed separately, so publishing a new post doesn't require rewriting the blog's main page.

Open Source

Built in the open.

BrackOS is an open-source operating system project. The source code, documentation, and development process are intended to remain accessible to people who want to learn from the project, experiment with it, or contribute to it.

What's next?

There isn't a rigid schedule for every future feature. We'll continue developing the operating system as the project progresses, documenting things as they become available.

For now, the focus is on making the existing project easier to understand and giving BrackOS a solid foundation to grow from.

And yes, that includes finally making the website less of a mess.
