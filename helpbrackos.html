Get involved

Help build Brack OS.

You don't need to be an operating system expert to help. Brack OS is being built by a small team, and every bit of support helps.

Spread the word

You don't have to write code to help us.

If you know someone who enjoys programming, operating systems, hardware, or just tinkering with computers, tell them about Brack OS.

Test Brack OS

Once builds become available, testing will be a huge part of making the project better.

Finding bugs, reporting problems, and telling us what went wrong can be just as useful as writing code.

Write code

If you know C, assembly, or systems programming, we'd love to hear from you.

There may eventually be opportunities to help with the kernel, drivers, tools, and other parts of the system.

Improve the project

Code isn't the only thing that needs work.

Documentation, testing, website improvements, ideas, and feedback can all make the project better.

Want to work with us?

Send us an email and tell us a little about yourself, what you'd like to help with, and what you can do.
